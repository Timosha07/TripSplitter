# Запуск на этом ПК

1. Открой `.env` в папке проекта.
2. В строке `BOT_TOKEN=` вставь токен после знака `=` и сохрани файл.
3. Запусти `start.cmd` двойным щелчком. Он поднимет локальную базу, проверит
   схему и запустит бота. Окно должно оставаться открытым, пока бот работает.
4. В Telegram отправь `/start`, затем `/join`. Остальные участники тоже должны
   отправить `/join` до добавления общей траты.

Бот работает, пока включён компьютер и открыт процесс запуска. Если этот же
токен используется ботом на другом сервере, сначала останови тот процесс.

Для остановки бота нажми Ctrl+C. Затем `stop-database.cmd` остановит базу.
После перезагрузки достаточно снова открыть `start.cmd`.

База `tripsplitter_v2` находится в `.local/postgres`, слушает только
`127.0.0.1:55440` и защищена автоматически созданным паролем. Это отдельный
кластер PostgreSQL: настройки существующих баз не меняются. Сохраняй `.env`
и данные `.local` при переносе проекта. Для резервного копирования работающей
базы используй `pg_dump`; простое копирование каталога при запущенной БД
не гарантирует корректную копию.

Токен и локальные данные исключены из Git. Программный код менять для токена
не требуется. Скрипты рассчитаны на Windows, установленную PostgreSQL и
подготовленное виртуальное окружение `.venv`.
